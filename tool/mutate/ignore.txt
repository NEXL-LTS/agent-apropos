# Equivalent mutants: reviewed suppressions for the mutation gate.
#
# An entry here says a mutant CANNOT change observable behaviour — not that its
# behaviour is unasserted. If the mutated code could behave differently, the
# answer is a fix or a justified pinning spec, never an entry here. Entries are
# reviewed in the PR that adds them, like any other suppression.
#
# Tab-separated, five fields:
#
#   <source path>  <occurrence>  <original>  <mutated>  <reason>
#
# `original` and `mutated` are the trimmed line text, with any inserted line
# folded on with a literal \n. `occurrence` is the 1-based index of `original`
# among the identically-trimmed lines of that file: mutant numbering shifts with
# rule order and line numbers shift with any edit above them, so neither is a
# stable key, and the text pair alone would exempt every identical line at once.
#
# An entry whose original text no longer appears at that occurrence fails the
# run as stale, rather than sitting here exempting nothing.
